📚 **Online Book Exchange System (OBES)**

OBES is a web-based platform that allows students to buy, sell, exchange, or share used academic books. Built using HTML, CSS, JavaScript, Firebase Authentication, and Cloud Firestore, the system enables students to list books, browse available listings, send book requests, manage exchanges, and communicate with other students through chat.

**Key Features:**
- User registration and login
- Add, browse, search, and filter book listings
- Buy, sell, exchange, or share books
- Send and manage book requests
- Accept or decline exchange requests
- Real-time updates using Firebase
- Student-to-student chat
- Responsive and user-friendly interface

**Tech Stack:** HTML, CSS, JavaScript, Firebase Authentication, Cloud Firestore.

The goal of OBES is to make academic resources more affordable, accessible, and sustainable by encouraging students to reuse and exchange books.
